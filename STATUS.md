## Session 12d (27 Sep) — real cause found and fixed ✅
- Read John's actual Chrome console via computer-use (read-only screenshot; John opened DevTools with Cmd+Option+J): `Uncaught ReferenceError: hx0 is not defined` at game.js:158, repeating.
- Cause: my 12b edit (brigade tag on hover) put a `//` comment mid-line, commenting out the `const [hx0, hy0] = …` declaration. Hovering any unit threw inside draw() between cx.save() and cx.restore(), so the camera transform stacked up every frame (drifted to −77,000 px) → smeared map, units off-screen.
